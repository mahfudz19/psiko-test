# Program Studi Sarjana (S1) Informatika

**Universitas Almarisah Madani**

## Deskripsi Program Studi

Program Studi Teknik Informatika adalah program pendidikan tinggi yang bertujuan untuk mempersiapkan mahasiswa dalam memahami, menerapkan, dan mengembangkan teknologi informasi dan komputer. Program studi ini memberikan landasan yang kuat dalam bidang teknologi informasi, komputasi, dan pengembangan perangkat lunak.

## Bidang Pengetahuan (Konsentrasi Inti)

Mahasiswa akan mempelajari dan mengembangkan kompetensi pada area berikut:

- Pengetahuan Komputasi
- Pengembangan Perangkat Lunak
- Jaringan Komputer
- Basis Data
- Kecerdasan Buatan
- Keamanan Informasi
- Analisis Data

---

## Peluang Karir

Lulusan program ini memiliki peluang karir yang luas di berbagai sektor, termasuk pengembangan perangkat lunak, analisis data, keamanan informasi, konsultasi teknologi, dan wirausaha teknologi. Profil karir lulusan meliputi:

- Pengembang Perangkat Lunak (_Software Developer_)
- Arsitek Perangkat Lunak (_Software Architect_)
- Administrator Jaringan (_Network Administrator_)
- Analis Keamanan Informasi (_Information Security Analyst_)
- _Data Scientist_
- Konsultan Teknologi
- Pengembang Aplikasi Mobile (_Mobile App Developer_)
- Peneliti Teknologi
- Wirausaha Teknologi (_Tech Entrepreneur_)

### Kurikulum Merdeka Belajar - Kampus Merdeka (MBKM)

Mahasiswa dapat memilih salah satu dari 2 opsi berikut untuk menempuh tahap akhir perkuliahan:

**PILIHAN 1 (Fokus Lintas Disiplin/Luar Kampus):**

- **Semester 6:** Pilihan Pembelajaran Lintas Disiplin (20 SKS)
- **Semester 7:** Pilihan 8 bentuk Kegiatan Pembelajaran di luar Universitas Almarisah Madani (20 SKS)
- **Semester 8 (Total 8 SKS):** Tugas Akhir (6 SKS) dan Perbankan (2 SKS)

**PILIHAN 2 (Fokus Konsentrasi Keahlian Dalam Kampus):**
