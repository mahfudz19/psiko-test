# [cite_start]Buku Petunjuk Penggunaan Aplikasi Penerimaan Mahasiswa Baru Universitas Almarisah Madani [cite: 1, 2, 3]

## [cite_start]Pendahuluan [cite: 4]

### [cite_start]A. Tujuan [cite: 5]
[cite_start]Dokumen aplikasi Penerimaan Mahasiswa Baru (PMB) ini dibuat dengan tujuan: [cite: 6]
1. [cite_start]Menggambarkan sistem PMB untuk Admin dan Peserta. [cite: 6]
2. Sebagai panduan penggunaan Aplikasi PMB. [cite_start]Admin dapat menggunakan dokumen ini sebagai panduan untuk mengatur, memverifikasi dan menetapkan jadwal proses penerimaan mahasiswa baru, sedangkan peserta dapat menggunakan dokumen ini sebagai panduan untuk mengetahui cara pendaftaran menggunakan aplikasi ini. [cite: 7]

### [cite_start]B. Cara Penggunaan Aplikasi [cite: 8]
1. [cite_start]Buka web browser (Microsoft Edge, Google Chrome, Safari, Mozilla Firefox, dan lain-lain) kemudian ketik https://univeral.ac.id/ di kotak Alamat dan tekan Enter. [cite: 9]
2. Di halaman utama situs Universitas Almarisah Madani, tekan Admission kemudian Penerimaan Mahasiswa. [cite_start]Akan diarahkan ke halaman pendaftaran. [cite: 13]
3. Untuk pendaftaran pertama kali, tekan tombol Daftar. [cite_start]Sedangkan jika sudah melakukan pendaftaran atau memiliki Akun, tekan tombol Masuk. [cite: 14]

## [cite_start]Penggunaan Aplikasi Sebagai Peserta Calon Mahasiswa [cite: 15]

### [cite_start]A. Pendaftaran [cite: 16]
1. [cite_start]Masuk ke https://pmb.univeral.ac.id/, kemudian tekan tombol Daftar. [cite: 17]
2. [cite_start]Di halaman pendaftaran, pilih jenjang yang diminati. [cite: 18]
3. [cite_start]Masukkan Nomor Induk Kependudukan (NIK), kemudian tekan Submit. [cite: 33]
4. Lengkapi data diri atau profil. [cite_start]Jika semua data sudah lengkap, tekan Submit. [cite: 34]
5. [cite_start]Pendaftaran berhasil, akan mendapatkan nomor Virtual Account (VA) yang dapat digunakan untuk melakukan pembayaran pendaftaran. [cite: 35, 36]

### [cite_start]B. Masuk Ke Dalam Halaman Dashboard Pendaftar [cite: 50]
1. [cite_start]Masuk ke https://pmb.univeral.ac.id/, lalu tekan tombol Masuk. [cite: 51]
2. [cite_start]Masukkan NIK dan Password yang sudah didaftarkan sebelumnya, kemudian tekan Submit (Jika belum, silakan tekan tombol Registrasi untuk melakukan pendaftaran). [cite: 52, 53]

### [cite_start]C. Tampilan dan Fungsi Dari Halaman Dashboard Pendaftar [cite: 59]
1. [cite_start]Tempat navigasi untuk Halaman Dashboard, Edit Profil & Data, Upload Dokumen dan Ubah Password. [cite: 118]
2. [cite_start]Tempat untuk melakukan pendaftaran baru jika peserta berniat untuk memilih jenjang atau program studi yang lain. [cite: 119]
3. [cite_start]Daftar grup untuk menerima atau bertanya informasi tentang Jurusan yang dipilih. [cite: 120]
4. [cite_start]Status pilihan peserta pendaftaran untuk program studi yang diminati dan tempat untuk upload bukti pembayaran. [cite: 121] [cite_start]Status akan berubah berdasarkan verifikasi dari panitia. [cite: 122]
5. Tempat untuk melihat proses dari kelengkapan data peserta. [cite_start]Baik data pribadi dan orang tua, maupun berkas yang sudah di upload dari Halaman Upload Dokumen. [cite: 123]

### [cite_start]D. Melengkapi Profil Peserta [cite: 125]
1. [cite_start]Di Halaman Dashboard peserta, tekan tombol Edit Profil & Data. [cite: 126]
2. [cite_start]Terdapat dua bagian, yaitu Data Anda dan Data Orang Tua. [cite: 127]
3. [cite_start]Lengkapi salah satu bagian dan submit sebelum menuju ke bagian lain. [cite: 131]
4. [cite_start]Persentase kelengkapan data dapat dilihat di Halaman Dashboard Peserta. [cite: 132]
5. [cite_start]Jika ada Data yang salah atau ingin diperbaharui, tekan tombol Data Anda atau Data Orang Tua untuk memperbaharui data yang ada kemudian tekan tombol Submit. [cite: 137, 138]

### [cite_start]E. Upload Berkas Peserta [cite: 139]
1. [cite_start]Di Halaman Dashboard peserta, tekan tombol Upload Dokumen. [cite: 140]
2. [cite_start]Pilh Jenis dokumen, kemudian tekan Choose File untuk memilih dokumen yang akan diupload (Maksimal 2MB). [cite: 141]
3. [cite_start]Jika sudah tekan Upload File. [cite: 152]
4. [cite_start]Jika dokumen berkas berhasil diupload, peserta dapat mengecek dokumen di Halaman Dashboard yang akan muncul ketika sudah diupload. [cite: 153, 154]

### [cite_start]F. Upload Bukti Pembayaran [cite: 158]
1. [cite_start]DI Halaman Dashboard peserta, tekan tombol upload bukti pembayaran. [cite: 159]
2. [cite_start]Untuk jenis dokumen tidak perlu diubah karena sudah tepat Bukti Pembayaran. [cite: 161]
3. [cite_start]Tekan choose File untuk memilih bukti pembayaran yang akan diupload (Maksimal 2MB). [cite: 169]
4. [cite_start]Jika sudah tekan tombol Upload File. [cite: 170]
5. [cite_start]File sudah terupload dan dapat di cek di Halaman Dashboard peserta. [cite: 171]

## [cite_start]Penggunaan Aplikasi Sebagai Panitia [cite: 173]

### [cite_start]A. Masuk Ke Dalam Halaman Admin [cite: 174]
1. [cite_start]Masuk ke https://pmb.univeral.ac.id/, lalu tekan tombol Masuk. [cite: 175]
2. [cite_start]Ketik akun yang telah diberikan di kolom NIK dan Password, tekan tombol Submit. [cite: 176]
3. [cite_start]Berhasil masuk ke dalam halaman Admin. [cite: 177]

### [cite_start]B. Fungsi Umum Halaman Admin [cite: 202]
1. [cite_start]Dashboard, berisi Informasi Jumlah Pendaftar, Jumlah Lulus dan Sumber Referensi. [cite: 203]
2. [cite_start]Pages, Berisi tentang data peserta yang akan diverifikasi, pengaturan jadwal tes dan penerbiatan NIM. [cite: 204]
3. [cite_start]Informasi, berisi Daftar Jadwal tes, peserta yang dinyatakan lulus dan data NIM yang telah diterbitkan. [cite: 210]
4. [cite_start]Setting, berisi tentang infomasi pendaftaran, fakultas, program studi, dan tagihan. [cite: 215]

### [cite_start]C. Proses Verifikasi Peserta Calon Mahasiswa dan Pembuatan Jadwal Ujian [cite: 222]
1. [cite_start]Di Halaman Dashbboard, tekan tombol Pages > Verifikasi Pendaftaran. [cite: 223]
2. [cite_start]Di halaman Verifikasi Pendaftaran, pastikan untuk mengecek kelengkapan berkas dan pembayaran yang telah dilakukan oleh peserta. [cite: 224]
3. [cite_start]Jika sudah tepat tekan tombol Verified yang sesuai dengan baris nama peserta. [cite: 251] [cite_start]Tunggu sebentar, akan muncul pesan bahwa verifikasi telah dilakukan. [cite: 252] [cite_start]Jika setelah melakukan Verifikasi pendaftaran ada kendala yang mengharuskan peserta belum berhak diverifikasi, dapat ditekan tombol Unverified di baris yang sama dengan nama peserta untuk membatalkan verifikasi. [cite: 256]
4. Selanjutnya yaitu membuat jadwal tes serta pemberian nomor ujian peserta. [cite_start]Tekan tombol Pages > Pengaturan Jadual Test. [cite: 257]
5. [cite_start]Centang nama peserta yang akan dibuatkan jadwal tes serta pemberian nomor ujian (Bisa lebih dari satu). [cite: 285] [cite_start]Gunakan kolom search untuk memudahkan pencarian atau bisa diurutkan dengan menekan kolom bertuliskan Nomor Ujian atau Status Jadwal. [cite: 286]
6. [cite_start]Tekan tombol Jadwal Tes, akan muncul jendela pembuatan jadwal. [cite: 287] [cite_start]Isi Waktu dan Lokasi tes di kolom yang tersedia (Untuk waktu Selesai Tes, dapat kosongkan jika belum diketahui waktu selesai tes). [cite: 288] [cite_start]Setelah Itu tekan tombol Save. [cite: 289]
7. [cite_start]Tunggu sebentar, akan muncul notifikasi bahwa jadwal berhasil dibuat dan dapat dilihat di Halaman Informasi > Daftar Jadwal Test. [cite: 301, 302]
8. [cite_start]Jika ingin mengubah atau menghapus jadwal, dapat dilakukan dengan cara mencentang tombol yang ada didalam kolom Check sesuai dengan nama pendaftar. [cite: 322] [cite_start]Kemudian tekan tombol Drop. [cite: 323]
9. [cite_start]Akan muncul pesan untuk memastikan bahwa data akan benar dihapus. [cite: 324] [cite_start]Tekan tombol Ya dan akan diberikan pesan bahwa date telah dihapus. [cite: 325]

### [cite_start]D. Verifikasi Peserta Yang Lulus [cite: 334]
1. [cite_start]Di Halaman Dashbboard, tekan tombol Pages > Verifikasi Pendaftaran. [cite: 335]
2. [cite_start]Tekan tombol Verified di kolom Verifikasi sesuai dengan nama peserta yang lulus. [cite: 373] Akan muncul pop up bahwa status nama peserta telah diverifikasi. [cite_start]Selanjutnya akan diarahkan di halaman Kelulusan Peserta. [cite: 374]
3. [cite_start]Pilih Prodi Yang Dilulusi dan Total Nilai Tagihan sesuai pilihan yang dilulusi oleh peserta kemudian tekan tombol Sumbit. [cite: 378] (Untuk Total Nilai Tagihan, Pilihan Bayar Full merupakan default yang sudah disetting sesuai dengan list Setup Prodi) [cite_start][cite: 379]
4. [cite_start]Verifikasi peserta yang lulus berhasil dan dapat dilihat melaluli halaman Informasi > Daftar Yang Lulus. [cite: 380]
5. [cite_start]Untuk membatalkan verifikasi peserta yang lulus, silahkan ke halaman Pages > Verifikas Yang Lulus. [cite: 381] [cite_start]Cari nama peserta kemudian tekan tombol Unverified (gunakan kolom search untuk mempermudah pencarian nama peserta). [cite: 382] [cite_start]Tunggu beberapa saat akan muncul bahwa peserta sudah diunverifikasi. [cite: 383]

### [cite_start]E. Penerbitan Nomor Induk Peserta (NIM) Peserta [cite: 384]
1. [cite_start]Di Halaman Dashbboard, tekan tombol Pages > Penerbitan NIM. [cite: 385]
2. Centang Kolom sesuai nama peserta yang akan diterbitkan NIM-nya (Bisa lebih dari satu centang). [cite_start]Selanjutnya tekan tombol Create NIM. [cite: 407, 408]
3. [cite_start]Akan muncul Pesan Untuk konfirmasi, tekan Ya. [cite: 410]
4. [cite_start]NIM berhasil diterbitkan dan dapat dilihat daftarnya di Halaman Informasi > Data NIM. [cite: 411]

### [cite_start]F. Pengaturan Periode Pendaftaran [cite: 412]
[cite_start]Untuk mengakes halaman periode pendaftaran, dapat dilakukan dengan menekan Tombol Setting > Periode Pendaftaran. [cite: 413, 414]
1. [cite_start]Menambahkan Data Periode Terbaru: Di halaman Periode pendaftaran, buat periode pendaftaran baru dengan menekan tombol Add Data. [cite: 440, 441] [cite_start]Masukkan data yang dibutuhkan sesuai periode pendaftaran yang dibuka, kemudian tekan tombol Save Changes untuk menyimpan periode pendaftaran. [cite: 448, 449]
2. [cite_start]Memperbaharui Data Periode: Untuk mengubah data yang ada di Periode Pendaftaran, tekan tombol berlogo edit di kolom action sesuai dengan baris data yang akan diubah. [cite: 450, 451] [cite_start]Perbaharui data yang diperlukan dan tekan tombol Save Changes untuk menyimpan perubahan. [cite: 452]
3. [cite_start]Menghapus Data Periode: Untuk menghapus data, tekan tombol berlogo tempat sampah di kolom action sesuai dengan baris data yang akan dihapus. [cite: 453, 454] [cite_start]Akan muncul notifikasi untuk menghapus data, tekan tombol OK untuk menghapus data. [cite: 455]

### [cite_start]G. Pengaturan Data Fakultas [cite: 456]
[cite_start]Untuk mengakses ke Data Fakultas, tekan Setting > Setup Fakultas [cite: 476]
1. [cite_start]Menambahkan Data Fakultas: Di halaman Setup Fakultas, Tambahkan fakultas baru dengan menekan tombol Add Data. [cite: 477, 478] [cite_start]Isi sesuai dengan nama fakultas baru, kemudian tekan Save Changes. [cite: 479]
2. [cite_start]Memperbaharui Data Fakultas: Untuk mengubah data yang ada di Setup Fakultas, tekan tombol berlogo edit di kolom action sesuai dengan baris data yang akan diubah. [cite: 488, 489] [cite_start]Perbaharui data yang diperlukan dan tekan tombol Save Changes untuk menyimpan. [cite: 490]
3. [cite_start]Menghapus Data Fakultas: Untuk menghapus data, tekan tombol berlogo tempat sampah di kolom action sesuai dengan baris data yang akan dihapus. [cite: 490, 491] [cite_start]Akan muncul notifikasi untuk menghapus data, tekan tombol OK untuk menghapus data. [cite: 492]

### [cite_start]H. Pengaturan Data Prodi [cite: 493]
[cite_start]Untuk mengakses ke Data Fakultas, tekan Setting > Setup Prodi. [cite: 516]
1. [cite_start]Menambahkan Data Prodi: Di halaman Setup Prodi, Tambahkan fakultas baru dengan menekan tombol Add Data. [cite: 517, 518] [cite_start]Isi sesuai dengan nama program studi baru dengan rincian: [cite: 519]
    * [cite_start]a) Nama Prodi merupakan nama Program Studi sesuai rincian. [cite: 520]
    * [cite_start]b) ID Progi, merupakan ID program studi sesuai aturan. [cite: 521]
    * [cite_start]c) Jenjang, terdiri dari D3, S1, Profesi, dan RPL. [cite: 522]
    * [cite_start]d) Biaya pendaftaran, dengan format 'reguler, transfer' (Contoh untuk Rp. 8.000.000 reguler dan Rp. 10.000.000 transfer, diketik 8000000,10000000). [cite: 523, 524]
    * [cite_start]e) Fakultas, dipilih berdasarkan Fakultas yang sama dengan Program Studi. [cite: 525] [cite_start]Setelah itu tekan Save Changes. [cite: 534]
2. [cite_start]Memperbaharui Data Prodi: Untuk mengubah data yang ada di Setup Prodi, tekan tombol berlogo edit di kolom action sesuai dengan baris data yang akan diubah. [cite: 537, 538] [cite_start]Perbaharui data yang diperlukan dan tekan tombol Save Changes untuk menyimpan. [cite: 539]
3. [cite_start]Menghapus Data Prodi: Untuk menghapus data, tekan tombol berlogo tempat sampah di kolom action sesuai dengan baris data yang akan dihapus. [cite: 540, 541] [cite_start]Akan muncul notifikasi untuk menghapus data, tekan tombol OK untuk menghapus data. [cite: 542]

### [cite_start]I. Pengaturan Data Tagihan Pendaftaran Ulang [cite: 543]
[cite_start]Untuk mengakses ke Data Tagihan Pendaftaran Ulang, tekan Setting > Setup Tagihan. [cite: 563]
1. [cite_start]Menambahkan Data Tagihan: Di halaman Setup Fakultas, tambahkan Tagihan baru dengan menekan tombol Add Data. [cite: 564, 565] [cite_start]Isi sesuai dengan nama fakultas baru, kemudian tekan Save Changes. [cite: 566]
2. [cite_start]Memperbaharui Data Tagihan: Untuk mengubah data yang ada di Setup Tagihan, tekan tombol berlogo edit di kolom action sesuai dengan baris data yang akan diubah. [cite: 572, 573] [cite_start]Perbaharui data yang diperlukan dan tekan tombol Save Changes untuk menyimpan. [cite: 574]
3. [cite_start]Menghapus Data Tagihan: Untuk menghapus data, tekan tombol berlogo tempat sampah di kolom action sesuai dengan baris data yang akan dihapus. [cite: 575, 576] [cite_start]Akan muncul notifikasi untuk menghapus data, tekan tombol OK untuk menghapus data. [cite: 577]

## [cite_start]Pertanyaan Yang Sering Diajukan / Frequenly Asked Question (FAQ) [cite: 578]

### [cite_start]A. Peserta Pendaftar [cite: 579]
* **1. [cite_start]Ketika mau masuk kedalam halaman Peserta, Peserta mendapatkan hasil ID, Nama, dan New Password kosong.** [cite: 580]
    * **Solusi:** Peserta sebelumnya telah mendaftar namun ketika ingin mesuk kedalam Halaman peserta, peserta masuk melalui halaman pendaftaran. [cite: 581, 585] Peserta diarahkan untuk masuk melalui halaman Login. [cite: 586]
* **2. [cite_start]Peserta tidak bila masuk dari halaman login** [cite: 608]
    * **Solusi:**
        * a. [cite_start]Coba ulang dengan memperhatikan NIK dan Password. [cite: 609, 610]
        * b. [cite_start]Dari Panita untuk melakukan Reset Password di Halaman Admin kemudian Password yang sudah direset diberikan ke Peserta. [cite: 611, 612]
        * c. [cite_start]Memakai browser lain (Google Chrome, Mozilla Firefox, Opera, Microsoft Edge, dan lain-lain) [cite: 614, 615]
        * d. [cite_start]Melakukan percobaan login dengan browser di device lain (Komputer atau Laptop). [cite: 616]
* **3. [cite_start]Ketika Upload file foto atau berkas, muncul pemberitahuan "Tidak ada file yang di-upload atau terjadi kesalahan"** [cite: 617]
    * **Solusi:** Ukuran foto dan berkas yang diupload melebihi batas maksimal yaitu 2MB. Silahkan melakukan pengecilan ukuran file. [cite: 620, 621]

### B. Admin / Panitia [cite: 622]
* **1. [cite_start]Ketika verifikasi peserta atau penerbitan NIM terdapat dua atau lebih hasil yang sama hasil yang sama.** [cite: 623, 624]
    * [cite_start]**Solusi:** Ketika melakukan konfirmasi untuk verifikasi atau penerbitan, dilakukan satu kali klik saja di tombol konfirmasi dan tunggu proses sistem untuk memunculkan notifikasi hasil. [cite: 625, 626] [cite_start]Ketika melakukan konfirmasi yang sama lebih dari satu kali, sistem akan menangkap pengiriman data yang menghasilkan informasi lebih dari satu kali. [cite: 627]
* **2. [cite_start]Nomor Ujian Belum Ada** [cite: 628]
    * **Solusi:** Lakukan pengaturan jadwal tes di Pages > Pengaturan Jadual Test untuk mendapatkan nomor ujian. [cite: 629, 630]
* **3. [cite_start]Berkas atau Foto tidak ditemukan/not found** [cite: 635]
    * **Solusi:**
        * [cite_start]Tutup jendela berkas yang muncul, kemudian buka berkas kembali. [cite: 636, 637]
        * [cite_start]Cek berkas lain yang diupload oleh peserta. [cite: 638]
        * [cite_start]Hubungi peserta yang bersangkutan untuk upload ulang file berkasnya. [cite: 639]
